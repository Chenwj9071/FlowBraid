# 技术选型说明

## 首版选型
- 运行时：Node.js
- 语言：TypeScript
- 执行模型：单进程长跑式 CLI 调度器

## 选择原因
- Node.js 对子进程编排、日志流和跨平台 CLI 支持成熟。
- TypeScript 适合把工作流定义、状态结构和执行器接口收紧。
- 首版以本地运行和文件落盘为主，不需要先引入服务端。

## 可复用能力
- `child_process.spawn`：执行本地 shell 命令并流式输出日志。
- `fs/promises`：管理 run workspace、状态文件和产物目录。
- `yaml`：兼容 YAML/JSON 工作流定义。
- `vitest`：做最小端到端测试。

## 首版不引入的东西
- 后台服务。
- 分布式调度。
- Web 控制台。
- 插件市场。
- 过度抽象的事件总线。

## 预留扩展点
- 执行器适配层可继续接入 `codex`、`claude`。
- 调度器可以从单进程 CLI 演进到守护进程模式。
- 目录与状态协议保持稳定后，可再考虑 UI 层。
